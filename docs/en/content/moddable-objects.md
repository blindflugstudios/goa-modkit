# Moddable objects

These are the objects you place from the build menu (props, workbenches and training objects) that a mod can give a new model, new textures and a new build-menu icon. To change one, name a file in your mod's `Objects/` folder after its id, for example `Chair.glb` or `Chair.thumbnail.png`. How the file names work is explained on [Objects and models](objects.md#file-names).

- Ids are matched without regard to capital letters: `chair.glb` works as well as `Chair.glb`.
- The built-in textures each object uses are listed on [Built-in texture names](texture-names.md).
- Trees, rocks and the other map objects are not in this list: a mod cannot change them yet.

This list was taken from the game's generated list of moddable objects on 2026-10-01.
